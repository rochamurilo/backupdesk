Opções de backup

Selecione arquivos e pastas, frequência e horário. O computador local já está preparado para criar rotinas.

Nova rotina

Clique em Selecionar pasta para abrir a janela do Windows. Para adicionar outra pasta, clique novamente. Unidades de rede precisam estar acessíveis ao seu usuário.

Onde salvar o backup

As versões serão salvas em uma subpasta BackupDesk. O destino precisa estar conectado e não pode ficar dentro da origem. HD externo ou rede ajudam a proteger contra falha do disco do computador.

Para PST com Outlook aberto, marque VSS e salve. O componente instalado inicia com o Windows e cria o snapshot automaticamente, sem abrir o painel como administrador. Suporta origem local NTFS. VSS é experimental: valide o PST restaurado no Outlook. Sem VSS, feche o Outlook.

Restauração

Restaurar arquivos

Escolha o computador e a versão concluída do backup. Depois selecione o arquivo para recuperar. O download é salvo pelo navegador na pasta escolhida por você.

A recuperação em disco cria uma pasta BackupDesk-Restaurado e não sobrescreve os originais. Para backups antigos no servidor, o arquivo é baixado pelo navegador.

Histórico de execuções

Aplicação em segundo plano. Backup em disco suporta arquivos grandes. O armazenamento legado no servidor mantém limite de 16 MiB. VSS experimental disponível com administrador; recuperação PST precisa ser validada no Outlook.

Vincular computadores client

Baixe o client pelo botão no canto inferior esquerdo. Use o token de vínculo para configurar o agente no outro computador.
